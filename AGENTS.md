# Правила проекта Virtual City для ИИ-разработчиков

Этот файл читают ChatGPT (Codex) и Claude (через CLAUDE.md). Владелец проекта — Vahe07, все решения по продукту принимает он.

## Что это
Один общий виртуальный город в браузере: изометрическая карта с жителями, транспортом и аэропортом, а поверх неё игровая экономика.
Каждая квартира, дом и бизнес — объект с номером, ценой и ежемесячным начислением. Объекты покупают целиком или долями, сдают, продают и дарят. Есть подарки, рейтинг и лента.
Сейчас это демо: одна страница, тестовые купоны, 12 демо-игроков (боты), прогресс хранится в браузере. Правила игры описаны в `docs/GAME-RULES.md`, план многопользовательской версии — в `docs/VC-009-multiplayer-plan.md`.

## Как устроен код
`index.html` в корне — собранный сайт для GitHub Pages. **Руками его не править**: изменения теряются при следующей сборке.
Код живёт в `src/` и собирается в один файл в таком порядке:

| Файл | Что внутри |
| --- | --- |
| `src/core.js` | константы карты, математика, случайные числа, цвета, форматирование текста |
| `src/data.js` | план города: карта, улицы, здания, бизнесы, имена, рейсы |
| `src/gen.js` | генерация города: здания, квартиры, жители, работа, декор |
| `src/geo.js` | геометрия зданий для отрисовки |
| `src/sim.js` | время, свет, машины, лодки, самолёты |
| `src/draw.js` | отрисовка на canvas, режим «Владение», метки и всплывающие пузыри |
| `src/game.js` | экономика: реестр объектов, доли, графики начислений, рынок, подарки, демо-игроки, сохранение |
| `src/ui.js` | интерфейс города: карточки, справочник, табло, жесты, камера, запуск |
| `src/gameui.js` | экраны игры: кабинет, рынок, рейтинг, лента, покупка, продажа, подарки, уведомления |
| `src/boot.js` | запускает всё после загрузки остальных частей |
| `src/style.css`, `src/shell.html` | стили и каркас страницы |

## Сборка и проверка
```
python3 build.py              # собрать index.html
python3 tests/test_game.py    # проверить в браузере (нужен playwright с chromium)
```
Перед каждым коммитом: собрать, прогнать тест, закоммитить `src/` вместе с новым `index.html`.

## Как работаем вдвоём
- Одна задача — одна ветка: `chatgpt/vc-0XX-кратко` или `claude/vc-0XX-кратко`. В `main` напрямую не пушить.
- Изменения попадают в `main` только через Pull Request, который принимает владелец.
- Нумерация задач продолжается: VC-001, VC-002 и дальше. Номер задачи — в названии ветки и PR.
- В описании PR: что сделано, зачем, как проверено. Если меняется экономика или формат сохранения, написать это отдельной строкой.
- Перед началом задачи подтянуть свежий `main`. Два ИИ не правят один и тот же файл в двух открытых PR одновременно без договорённости.

## Обязательные ограничения
- Только тестовые купоны. Никаких реальных платежей, вывода денег, криптовалют и обещаний реальной доходности. Подробнее в `docs/GAME-RULES.md`.
- Никаких ключей, паролей и токенов в коде: репозиторий публичный.
- Интерфейс на русском, сначала для телефона (iPhone, Safari), потом для компьютера.
- Не использовать `alert`, `confirm`, `prompt`, `window.open` и картинки с других сайтов: та же страница публикуется в Claude, где они заблокированы. Диалоги делать внутри страницы, графику рисовать кодом.
- Внешние скрипты нельзя, шрифты только Google Fonts.
- Город одинаковый при каждом открытии: генерация детерминирована. Не менять порядок вызовов случайных чисел в `gen.js` без необходимости, иначе сдвинутся все здания, жители и номера объектов, и старые сохранения перестанут подходить.

## Экономика: что нельзя сломать
- Сумма долей объекта не больше 100%. Доля кратна минимальной (`a.min`).
- Лот (`lot`) — владение объектом или долей. График привязан к лоту: `iss` — дата покупки у платформы, `k` — сколько месяцев уже начислено. При перепродаже и дарении они не меняются.
- Начисление раз в месяц в дату `iss`. Первые `s1` месяцев — окупаемость 100%, до `s2` — ещё +50%, дальше остаток 10% от месячного начисления.
- Квартира и дом приносят начисления, только если включено «Сдать в аренду» (`lot.rent`).
- Покупка подарка: 50% цены сразу получают владельцы бизнеса по долям, остальное — платформа.
- Обычный подарок нельзя продать дороже цены покупки, лимитированный — можно. Лимит выпуска не превышается.
- Комиссия рынка 2% с продавца.
- Формат сохранения: `packGame`/`unpackGame` в `game.js`, ключ `vc-demo-v1`, версия `SAVE_V`. Если меняете формат, увеличьте `SAVE_V` и опишите это в PR.

## Где хранится прогресс
В браузере (localStorage). Когда страница открыта внутри Claude как артефакт, она дополнительно сохраняет прогресс владельца в его личном пространстве (capability `db`). На GitHub Pages этого нет, там только браузер.
